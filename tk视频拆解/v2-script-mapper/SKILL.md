# V2 脚本结构映射器

## 输入
- 来自 v3-video-scanner 的帧时间线和场景节奏
- 来自 v2-hook-lift 的钩子诊断和 Lift 倍数
- 视频脚本/字幕文本（如有）

## 5段式结构映射

| 段落 | 时间 | 状态 | 实际情况（1-2句） |
|------|------|------|----------------|
| Hook 钩子 | 0-10% | ✅/⚠️/❌ | |
| Problem 痛点 | 10-35% | | |
| Solution 方案 | 35-65% | | |
| Proof 证据 | 65-90% | | |
| CTA 行动号召 | 90-100% | | |

## 病毒评分（5维度/100分 · 人工评分）

逐维对照根 SKILL.md「锚点定义」表打分，不要凭感觉。每维只能选 20/15/10/5 四档。

| 维度 | 分数 | 1句评价（必须说明选了哪档、为什么） |
|------|------|------|
| 钩子力 | /20 | |
| 收藏驱动 | /20 | |
| 分享驱动 | /20 | |
| 完播引导 | /20 | |
| 评论激活 | /20 | |
| **总分** | **/100** | <60 分标注全部拖分维度（≤10 的维度） |

## 硬规则检查（6项）

与 v3-tk-workflow 报告中的 6 条保持一致：

| 规则 | 状态 |
|------|------|
| 0-3秒内出现核心卖点信号（无废话开头） | ✓/✗ |
| 核心关键词在10秒内出现（静音可传达核心信息） | ✓/✗ |
| 有明确CTA行动引导（具体可执行） | ✓/✗ |
| 视频聚焦1个核心信息（不分散话题） | ✓/✗ |
| Problem/痛点显性化（明确说出来，不靠观众猜） | ✓/✗ |
| 产品差异化细节展示（不只说"好用"，给出证据） | ✓/✗ |

## 修复建议（仅针对❌和⚠️段落）

每条格式（最多3条）:
```
❌ [段落名]缺失
→ 加入: [具体内容，1句话]
→ 参考: [同品类案例，半句]
```

## 不输出
- ❌ Top 5公式匹配评分（与hook-lift重复）
- ❌ 预估提升分数（难以准确，增加tokens）
- ❌ 多于3条修复建议
