# V2 钩子 + Lift爆款识别

## 输入
- 来自 v3-video-scanner 的视频扫描结果（帧分析、场景节奏）
- 视频基础数据（播放量、点赞、评论、转发、收藏）
- 类目/赛道基准数据（用于 Lift 倍数对比）

## 输出结构

### 1. Lift倍数表

| 指标 | 该视频 | 基准 | Lift | 判定 |
|------|--------|------|------|------|
| 播放量 | | | x | |
| 点赞率 | | 2-5% | x | |
| 评论率 | | 0.05-0.1% | x | |
| 转发率 | | 0.02-0.05% | x | |
| 收藏率 | | 0.05-0.1% | x | |

判定: 5x+=超级爆款 / 2x-5x=强爆款 / 1-2x=正常 / <1x=低于平均

基准优先用账号中位数，无账号数据则用行业基准（标注）。样本<10条加⚠️。

### 2. 4问钩子诊断

| 问题 | 分析（2-3句） |
|------|------|
| 前3秒承诺了什么? | 视觉/话术/字幕三层，哪层是主驱动 |
| ~7秒模式中断? | 有→具体方式; 无→影响 |
| 算法为什么选中? | 结合最异常的Lift指标推断 |
| 可复制公式? | 1句泛化模板: `[X] + [Y] + [Z]` |

### 3. 主钩子类型
格式: `[类型名] (置信度: 高/中) — 1句匹配理由`
+ 简提2个次选类型（各半句）。

### 4. 互动率对标 & 爆款解读

| 指标 | 该视频 | 基准 | 表现 |
|------|--------|------|------|
| 点赞率 | | 2-5% | |
| 收藏/转发比 | | — | >1实用型/<1社交型 |

1句话总结: 互动模式类型（信息型/内容型/流量型）+ 核心驱动力。
