# V3 视频深度扫描器

## 输入

优先读取 **composite.jpg**（FFmpeg拼合缩略图，单张含所有帧）：
```
frames/composite.jpg       ← 单次读入，所有帧横向排列
frames/frames_meta.json    ← 帧时间戳: {"timestamps":[0,2,4,6,8,10], "n_frames":6, ...}
```
若无 composite，则按旧方式读取 `frame_00.jpg … frame_N.jpg`（单独文件）。

**Token优化**：1张composite = 读1次；6张单帧 = 读6次。composite 模式省约 80% 帧读取 token。

## 输出原则
- **流式输出**（编排器调用时）: 只输出关键信号，每项1句话
- **HTML报告素材**（最终报告）: 完整细节由编排器组装

## 输出结构

### 1. TL;DR
1句话: 视频核心内容 + 策略 + 驱动力。

### 2. 逐帧时间线（精简版）
**每帧1句话**，只描述关键变化/新信息，相似帧合并。

| 时间 | 描述（1句，重点是新变化+字幕原文） |
|------|------|
| 0:00 | **[功能词]** — 核心内容一句话（如有字幕用*斜体*引用） |

**帧数上限**: 视频≤30s 最多6帧; 30-60s 最多8帧; >60s 最多10帧。相邻帧画面无变化则合并为一行。

### 3. 3个关键帧（电商视角，各1-2句）

| 帧 | 时间 | 功能 | 电商价值（1句） |
|----|------|------|---------|
| 开场帧 | 0s | 钩子 | |
| 转折帧 | Xs | | |
| 收尾帧 | Xs | | |

### 4. 场景节奏（表格）

| 时间段 | 内容 | 转场 | 节奏 |
|--------|------|------|------|

+ 1句整体节奏评价。

### 5. 视觉、音频 & 制作层（合并为一张表）

| 维度 | 分析（1句） |
|------|------|
| 色彩主调 | |
| 产品出镜率 | |
| 人物元素 | |
| 文字叠加 | |
| 品牌露出 | （多品牌时列清单） |
| 音频类型 | 原创音频 / 热门音效 / 纯BGM（从音频听判断） |
| 口播/字幕 | |
| 音频设计意图 | |
| **剪辑节奏** | 估算每10秒切换次数：快剪≥5次 / 中节奏3-4次 / 慢节奏≤2次 |
| **封面帧停留力** | 首帧类型（人物特写/产品展示/文字冲击/动作瞬间）+ 是否有强视觉停留点 |
| **音乐节奏匹配** | 音乐节奏与剪辑速度是否一致（卡点剪辑=高完播信号；不匹配=完播拖累） |

### 6. 电商5维诊断（仅用于我方视频 Step 1）

每维只选 10/7/4 三档，对照以下锚点：

| 维度 | 10分 | 7分 | 4分 |
|------|------|-----|-----|
| 钩子时效 | 第1帧即有钩子，3秒内明确产品/痛点 | 有钩子但需3-8秒才出现 | 无钩子或产品 >10秒才出现 |
| 产品出镜 | 产品在前10秒出镜，且演示时间 ≥60% 视频时长 | 产品有演示但出镜时机延迟 >10秒 | 产品基本不出镜或仅在结尾短暂出现 |
| CTA布局 | CTA在视频最后20%，具体可执行（link in bio / orange cart / link below） | 有CTA但模糊（"check it out"）或位置偏早 | 无CTA或CTA缺失 |
| 留存机制 | 有显性悬念/倒数/before-after结构，或视频 ≤30秒 | 节奏尚可，无明显拖沓，时长30-60秒 | 有明显流失点或视频 >60秒且中段无新信息 |
| 卖点传递 | 聚焦单一核心卖点，有具体数字/对比/证据 | 有卖点但不够聚焦（2-3个） | 卖点分散 ≥4个或全程氛围型，无具体数字 |

| 维度 | 评分 | 1句分析（选了哪档+原因） |
|------|------|---------|
| 钩子时效 | /10 | |
| 产品出镜 | /10 | |
| CTA布局 | /10 | |
| 留存机制 | /10 | |
| 卖点传递 | /10 | |

## 不输出
- ❌ 视频编码/码率/文件大小/音频采样率
- ❌ 每帧2-3句（改为1句）
- ❌ 视频基础参数单独表格（时长从metadata直接读）
