# V3 评论洞察分析器

## 输入
tk_comment_scraper.py 生成的JSON（字段: text/user/likes/language/purchase_intent/time/replies）

## 输出结构

### 1. 概览（4个数字）
总抓取/购买意向率/创作者回复率/语言种类

### 2. 6类分布（数量+占比+每类1条代表评论）

| 类别 | 数量 | 占比 | 代表评论 |
|------|------|------|---------|
| 🛒 购买意向 | | | |
| ❓ 产品疑问 | | | |
| 👍 正面反馈 | | | |
| 👎 负面反馈 | | | |
| 🔗 网站/物流 | | | |
| 💬 社交互动 | | | |

### 3. 购买意向分层

| 层级 | 数量 | 代表评论（1条） |
|------|------|----------------|
| 强（明确要买/下单） | | |
| 中（问价/问渠道） | | |
| 弱（要信息/表兴趣） | | |

### 4. 语言分布（表格，按占比降序）

| 语言 | 占比 | 市场含义（1句） |
|------|------|----------------|

### 5. 高赞评论 Top 3（含创作者回复原文）

### 6. 创作者回复诊断（4项，每项1句）
- 回复率: X%（基准20-30%）
- 回复质量: 个性化/模板化（如模板化，引用重复话术）
- 最大遗漏: 哪条高赞未被回复
- 改进建议: 1条最重要的

### 7. 关键信号（4项，每项1句）
- 最高频问题
- 意外发现（视频分析检测不到的）
- 投诉/痛点
- 未满足需求

### 8. 验证矩阵（3行，每行1句证据）

| 其他Step的判断 | 验证 | 证据（1句） |
|----------------|------|------------|
| Step 3 CTA判断 | ✅/❌/🆕 | |
| Step 2 爆款信号 | ✅/❌/🆕 | |
| Step 1 电商5维弱项 | ✅/❌/🆕 | |

## 无评论时
输出1行: "⚠️ 评论数据不可用，跳过本模块"

## 不输出
- ❌ 购买意向转化漏斗图（表格已覆盖）
- ❌ 每类别多于1条代表评论
- ❌ 受众跨境分析段落（整合入语言分布）
