# 快速开始 — 员工使用指南（v6.3）

## 前置条件

### 必须
1. **Claude Code** 已安装（桌面版或 CLI 均可）
2. **FastMoss MCP** 已连接且额度充足
   - 一次完整分析约消耗 25-35 次 API 调用
   - 如额度不足会提示充值

### 可选
- **Chrome MCP**：仅在 FastMoss 完全不可用时的备选数据源

## 使用步骤

### 1. 打开项目
在 Claude Code 中打开 `listing和竞品分析` 文件夹：
- 桌面版：文件 → 打开文件夹 → 选择 `listing和竞品分析`
- CLI：`cd` 到该目录后运行 `claude`

### 2. 输入分析请求
直接输入以下任一格式：

```
帮我分析这个产品 [产品链接]
```

```
帮我诊断 [店铺名] 的产品
```

```
分析 [关键词] 类目的竞品
```

**示例**：
```
帮我分析这个产品 https://shop.tiktok.com/view/product/1729440713481294190
```

> **提示**: 如果信息不够（比如没给链接、给了其他平台的链接、只说了店铺名但没指定产品），Claude 会反问你补充信息，按提示回答即可。

### 3. 等待执行
Claude 会自动：
1. 读取 SKILL.md 工作流
2. 分 5 个阶段采集数据（A定位 → B本品 → C大盘 → D竞品 → E诊断）
3. 中间结果写入本地文件（01-10），逐批处理防上下文溢出
4. 生成 Markdown 报告，发布为在线 Artifact

整个过程约需 5-10 分钟，中途无需干预。

### 4. 获取报告
分析完成后会得到：
- 一份 Markdown 报告（Artifact 链接，可在线查看和分享）
- 报告包含 4 大板块：概览 → 竞品矩阵 → Listing诊断 → 风险评估

## 报告包含什么

| 板块 | 内容 |
|------|------|
| ★ 概览 | ①产品数据 ②L3大盘 ③店铺 ④28天趋势 ⑤MSKU变体 ⑥对标竞品 |
| Section 1 竞品矩阵 | 7+3 矩阵（≥16行×12列）+ 形态生存力验证 + 达人流量对比 + 佣金策略 |
| Section 2 Listing诊断 | 六维度评分 + 标题/描述/SEO + 图片优化 + 评论分析 |
| Section 3 风险评估 | ≥5条风险卡片（高/中/低）+ 应对措施 |

## 常见问题

### Q: FastMoss 提示余额不足怎么办？
A: 登录 FastMoss 后台充值。一次完整分析约需 25-35 个额度。

### Q: 能只跑竞品分析不跑 Listing 诊断吗？
A: 目前是合并工作流，建议完整跑一遍。如果只需要部分内容，可以告诉 Claude "只帮我做竞品分析部分"。

### Q: 评论数据返回 0 条怎么办？
A: FastMoss 评论 API 不限评论数都会先尝试（≥500 评论商品通常有数据）。API 返回 0 条时，工作流自动用爬虫 SSR 提取 3 条评论样本兜底。

### Q: 可以分析非 US 市场吗？
A: 工作流默认分析 US 市场。如需其他市场，在请求中注明，如 "帮我分析 UK 市场的这个产品"。

## 文件结构

```

├── CLAUDE.md          ← Claude Code 自动读取的入口
├── SKILL.md           ← 主工作流（唯一权威，5阶段流程）
├── 快速开始.md         ← 本文件
└── skills/
    ├── 01-数据采集.md       ← 阶段 B 本品取数
    ├── 02-增强竞品矩阵.md   ← 阶段 C/D 大盘+竞品
    ├── 03-标题描述诊断.md   ← Section 2.1
    ├── 04-图片视频诊断.md   ← Section 2.2
    ├── 04B-商品详情页诊断.md ← Section 2.2 补充
    ├── 05-SEO关键词诊断.md  ← Section 2.1 选词
    ├── 06-定价佣金诊断.md   ← 并入矩阵
    ├── 07-达人内容诊断.md   ← Section 1.2
    ├── 08-合规评论诊断.md   ← Section 2.3
    ├── 08B-VOC消费者洞察.md ← Section 2.3 辅助
    ├── 09-竞品深度分析.md   ← Section 1 辅助（不额外调API）
    ├── 10-市场定位与差异化.md ← Section 3 辅助（不引入新数据）
    ├── 11-综合评分.md       ← 六维度评分
    ├── 12-统一报告格式.md   ← Markdown 结构模板
    └── 13-评论爬虫.md       ← 评论降级方案
```

> **注意**：SKILL.md 是唯一权威，与 skills/ 子文件冲突时以 SKILL.md 为准。
