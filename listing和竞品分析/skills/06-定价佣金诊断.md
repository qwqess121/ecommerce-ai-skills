## 到手价计算（见 SKILL.md §四）

```
到手价          = 售价 + 运费
创作者单笔收入   = 售价 × 佣金率
28天成交均价     = 28天GMV ÷ 28天销量
```

## 矩阵中的定价相关行

矩阵行序中包含以下定价字段（均为实取值，禁止估算）：

| 行 | 字段 | 来源 |
|----|------|------|
| 价格 | `floor_price` | `product_detail_info` / 榜单 |
| 佣金率 | `commission_rate` | `product_detail_info` |
| 运费 | `shipping_fee` | `product_detail_info` |
| 到手价 | 售价 + 运费 | 派生 |
| 创作者单笔收入 | 售价 × 佣金率 | 派生 |

## 佣金策略分析要点

1. **佣金与达人关联**：佣金率高的产品达人数是否也更多？创作者单笔收入与达人合作数量是否正相关？
2. **渠道结构关联**：高佣金产品的达人渠道 GMV 占比是否更高？低佣金产品是否依赖商品卡被动流量？
3. **佣金策略建议**仅在 Section 1.2 出现一次（达人与流量结构部分），Section 2 不得重复

## 评分

满分 10 分（定价与佣金维度），内部算法见 SKILL.md §八（禁止写进报告）。报告只出 `X/10`。

## 固定输出格式

定价与佣金**不单独成节**，数据嵌入 Section 1 矩阵的以下行：

| 矩阵行 | 数据 | 来源 |
|--------|------|------|
| 价格 | $X.XX–$X.XX | detail_info.floor_price / ceiling_price |
| 佣金率 | X% | detail_info.commission_rate_percent |
| 运费 | $X.XX 或 免运费 | detail_info.shipping_fee |
| 到手价 | $X.XX（= 售价+运费） | 派生 |
