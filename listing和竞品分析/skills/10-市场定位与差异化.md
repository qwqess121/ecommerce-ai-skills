## 一、数据来源（v6.2 重大变更）

> **`market_category_analysis` 已停用**。该 API 仅支持 L1 类目（含轮胎车灯等无关品类，基数严重失真）。

### 1.1 市场数据一律用 L3 口径

所有大盘数据来自 **L3 榜单 1-50 名逐条加总**（在 Step 2 市场格局扫描中已完成）：
- 总销量/总 GMV → 榜单 50 条加总

- CR3/CR5 → 头部品牌销量占比

## 二、形态可行性结论

> 直接引用 09-竞品深度分析 的 4 项证据框架结果，在 Section 3 输出最终判定。

### 2.1 "蓝海"警告规则

**绝对禁止**把"同形态竞品少"直接写成蓝海机会。必须：
1. 列出 4 项证据的逐项结果（通过/未通过 + 数据）
2. 给出分层结论（见 09 的 1.2 分层表述规则）
3. 分开表述："形态是否成立" vs "本品子形态是否被验证过"

### 2.2 输出格式（引用 SKILL.md §6.3 四项证据）

```
形态生存力验证：
① 还在卖吗？— [逐款数据]
② 有新入场者吗？— [逐款数据]
③ 零销量 = 没需求还是没推广？— [推广数据对比]
④ 赢家长什么样？— [共同特征 vs 本品差异]
分层结论：[形态是否成立] + [本品子形态是否被验证]
```

## 三、市场风险识别

### 3.1 风险维度

| 风险类型 | 评估方法 | 数据来源 |
|---------|---------|---------|
| **价格战风险** | 近 4 周均价下降幅度、低价新品涌入速度 | L3 榜单趋势 |
| **集中度风险** | CR3 > 60% 则头部垄断，新进入者难度高 | L3 榜单加总 |
| **合规风险** | 类目是否有特殊资质要求、近期下架案例 | Listing 诊断结果 |
| **季节性风险** | 品类是否强季节性、当前处于什么阶段 | 销量趋势曲线 |
| **达人依赖风险** | 销量过度依赖少数达人 | Section 1 达人数据 |

### 3.2 风险等级

- **高风险**：该维度存在明确威胁，需在 30 天内应对
- **中风险**：需关注但非紧急，建议 90 天内制定预案
- **低风险**：当前可控，持续监测即可

## 四、战略建议

基于风险评估 + 形态可行性 + 竞品矩阵洞察，输出：

1. **进入策略**：是否建议进入 / 谨慎进入 / 不建议进入
2. **差异化方向**：基于痛点交叉分析的 Top 3 机会点
3. **优先行动项**：按紧急程度排序的 3-5 条具体建议

> 战略建议必须有数据支撑，禁止空泛的"建议加强运营"类表述。

## 五、固定输出格式（换任何产品都必须按此结构输出）

Section 3 风险评估包含以下固定输出，顺序不可调整：

### 输出 A：风险卡片（≥5 条，按严重程度排列）

每条风险用统一格式：

```
[高/中/低风险] [风险标题]
问题描述：[1-2句话说明风险本质]
影响范围：[影响什么、多严重]
应对措施：[具体可执行的建议；已在前文详述的用"详见 Section X"]
```

风险类型须覆盖但不限于：
- 运营风险（发货率/库存/服务指标）
- 产品风险（形态验证/功能缺陷/内容可拍性）
- 竞争风险（价格战/头部垄断/新入场者）
- 合规风险（资质/描述合规/知识产权）
- 达人风险（渠道依赖/达人流失/佣金竞争力）

### 输出 B：30天优先行动项（3-5 条）

| 优先级 | 行动项 | 预期效果 | 依据（引用前文数据） |
|--------|--------|---------|-------------------|
| 极高 | [具体行动] | [量化预期] | [引用 Section X 的具体数据] |
| 高 | ... | ... | ... |
| 中 | ... | ... | ... |

- 每条行动项必须有数据支撑，禁止空泛的"建议加强运营"类表述
- 预期效果尽量量化（如"达人数 5→25+"、"周GMV $264→$1,000+"）

### 产出规则

- 基于前文已诊断问题汇总，**不引入新数据**
- 重复的行动细节用"详见 Section X"引用
- 风险卡片不少于 5 条
