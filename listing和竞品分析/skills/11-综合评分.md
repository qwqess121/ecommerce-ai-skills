## 二、内部计算公式（禁止展示）

每个维度的 10 分由四个等权分项合成：

```
维度得分 = 审计合规 × 25% + 竞品对比 × 25% + 大盘基准 × 25% + 评论验证 × 25%
```

| 分项 | 含义 |
|------|------|
| 审计合规 | 该维度的合规性与质量（Listing 诊断结果） |
| 竞品对比 | 本品 vs TOP10 竞品在该维度的相对表现 |
| 大盘基准 | 该维度在 L3 类目大盘中的相对位置 |
| 评论验证 | 用户反馈对该维度的佐证（评论情感分析） |

> **硬性规则**：此公式仅供内部计算，**绝对不得出现在报告中**。报告中不展示权重、不展示分项、不展示公式。

## 三、报告展示规则

### 3.1 只出数字

- 单维度：`X/10`
- 总分：`X/60`
- 示例：`标题与SEO: 7/10`、`综合评分: 42/60`

### 3.2 禁止展示的内容

| 禁止项 | 说明 |
|--------|------|
| 权重百分比 | 不展示 25% 等权重 |
| 分项明细 | 不展示"审计 3.5 × 25% + ..." |
| 进度条 | 不使用 `.score-bar` 等 CSS 进度条 |
| 环形图 | Markdown 下不使用 SVG 环形图，改用数字 `X/60` + `X/10` 直接展示 |
| 计算过程 | 不展示任何中间计算步骤 |

### 3.3 评分标签映射

| 得分 | Markdown 标记 | 含义 |
|------|-------------|------|
| 8-10 | **X/10** | 优秀 |
| 6-7 | **X/10** | 中等偏上 |
| 4-5 | **X/10** ⚠️ | 需优化 |
| 1-3 | **X/10** ⛔ | 需优先改进 |
