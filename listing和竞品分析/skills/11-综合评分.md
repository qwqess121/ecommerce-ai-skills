# 综合评分（v6.2）

> **权威规则见 SKILL.md §八 评分规定**，本文件仅做快速参考。

## 一、评分体系

**6 维度 × 10 分 = 满分 60 分**

| # | 维度 | 说明 | 对应报告 |
|---|------|------|----------|
| 1 | 标题与 SEO | 关键词覆盖、可读性、字符利用率、搜索意图匹配 | Section 2 |
| 2 | 图片与详情页 | 主图质量、信息图/卖点图、SKU 缩略图、详情页体验 | Section 2 |
| 3 | 定价与佣金 | 价格区间定位、佣金竞争力、SKU 阶梯策略 | Section 2 |
| 4 | 达人与内容 | 达人数量/活跃度、视频 GMV 占比、内容生态健康度 | Section 1 |
| 5 | 评论与口碑 | 评分、评论数、好评率、差评主题、店铺服务指标 | Section 2 |
| 6 | 市场与竞争 | 品类增长趋势、竞争集中度、形态可行性、增长动能 | Section 1 + 3 |

---

## 二、内部计算公式（禁止展示）

每个维度的 10 分由四个等权分项合成：

```
维度得分 = 审计合规 × 25% + 竞品对比 × 25% + 大盘基准 × 25% + 评论验证 × 25%
```

| 分项 | 含义 |
|------|------|
| 审计合规 | 该维度的合规性与质量（Listing 诊断结果） |
| 竞品对比 | 本品 vs TOP10 竞品在该维度的相对表现 |
| 大盘基准 | 该维度在 L3 类目大盘中的相对位置 |
| 评论验证 | 用户反馈对该维度的佐证（评论情感分析） |

> **硬性规则**：此公式仅供内部计算，**绝对不得出现在报告中**。报告中不展示权重、不展示分项、不展示公式。

## 三、报告展示规则

### 3.1 只出数字

- 单维度：`X/10`
- 总分：`X/60`
- 示例：`标题与SEO: 7/10`、`综合评分: 42/60`

### 3.2 禁止展示的内容

| 禁止项 | 说明 |
|--------|------|
| 权重百分比 | 不展示 25% 等权重 |
| 分项明细 | 不展示"审计 3.5 × 25% + ..." |
| 进度条 | 不使用 `.score-bar` 等 CSS 进度条 |
| 环形图 | 不使用 SVG 环形评分图 |
| 计算过程 | 不展示任何中间计算步骤 |

### 3.3 颜色映射（Score Pill）

| 得分 | CSS 类 | 含义 |
|------|--------|------|
| 8-10 | `.score-pill .sp-g` | 优秀 |
| 6-7 | `.score-pill .sp-y` | 中等偏上 |
| 4-5 | `.score-pill .sp-o` | 需优化 |
| 1-3 | `.score-pill .sp-r` | 需优先改进 |
