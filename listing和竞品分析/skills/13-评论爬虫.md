# 13 - TikTok 评论爬虫工具（v6.3）

> **定位**: 独立工具 Skill，在 FastMoss `product_review_list` 返回 0 条时作为 **Level 1.5** 降级方案获取评论样本 + 全量评分分布。
> 与报告结构无强耦合，适用于任何需要评论数据的场景。
>
> **注意**: 如需同时获取描述正文+图片+评论+评分分布（Batch 5.5 场景），推荐使用**全量版** `tiktok_product_scraper.py`，它复用了同样的 SeleniumBase UC 反爬能力，一次运行提取所有数据。本脚本仅在只需评论时使用。

## 评论获取策略（两层）

| 层级 | 方式 | 能力 | 条件 |
|------|------|------|------|
| **Layer 1** | FastMoss `product_review_list` | 多条完整评论原文（10+条） | 不限评论数都先尝试，≥500 评论商品通常有数据 |
| **Layer 2** | 本爬虫 SSR 提取 | 3 条评论样本 + 全量评分分布 | API 返回 0 条时兜底 |

**关键原则**：FastMoss API 是评论原文的主力来源，不限评论数量都先调用。只有 API 返回 0 条时才用爬虫兜底。

## 技术限制（2026-09 深度实测）

TikTok Shop 的反爬保护导致以下方案均不可行：

| 尝试的方案 | 结果 | 原因 |
|-----------|------|------|
| API 拦截（fetch/XHR monkey-patch） | 失败 | Service Worker 拦截了所有请求，JS 层面无法捕获 |
| 直接调用 `get_product_reviews` API | 失败 | `X-Tts-Oec-Bsid` token 是一次性的、绑定浏览器会话，无法重放 |
| DOM 翻页（点击 Next） | 失败 | headless 模式下 API 返回空值，DOM 不更新 |
| URL 分页参数（?review_page=2） | 失败 | SSR 永远返回相同的 3 条评论 |
| 浏览器 cookies 导出 + requests 库 | 失败 | API 返回 404，token 校验不通过 |
| CDP Network 拦截 | 失败 | 只能看到请求 URL，无法获取响应正文 |

**结论**：SSR 的 3 条评论是爬虫能可靠获取的上限。评论原文的主力必须依靠 FastMoss API。

## 使用方法

### 命令

```bash
python scripts/tiktok_review_scraper.py {product_id}
python scripts/tiktok_review_scraper.py {product_id} --visible  # 办公电脑推荐
```

**参数**: `product_id` — TikTok Shop 商品 ID（17-19位数字）

### 输出字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `product_id` | string | 商品 ID |
| `reviews` | array | 3 条评论样本（source: "ssr"），每条含 review_id/rating/text/user_name/date/country/sku/images |
| `total_reviews` | int | 实际获取的评论条数（固定为 3） |
| `total_reviews_reported` | int | 商品页报告的总评论数 |
| `avg_rating_page` | float | 全量平均评分（基于所有评论） |
| `rating_distribution_page` | object | 全量评分分布（如 `{"5": 21, "4": 0, "3": 1, "2": 2, "1": 3}`） |

## 技术原理

### 反爬策略

1. **SeleniumBase UC (Undetected Chrome) 模式**：自动绕过 TikTok 反爬检测和 CAPTCHA
2. **SSR 数据提取**：从页面 `<script id="__MODERN_ROUTER_DATA__">` 提取服务端渲染数据
3. **无需登录**：不需要 TikTok 账号，不需要 Cookie

### 数据提取路径

```
SSR JSON 结构:
└── loaderData
    └── product-detail_$id/page
        └── page_config → components_map[N]
            └── component_data
                └── review_info
                    ├── reviews → 3 条评论原文（固定，无法翻页）
                    └── review_ratings
                        ├── overall_score → 全量平均评分
                        ├── review_count → 总评论数
                        └── rating_result → 全量评分分布 {"1":"3","2":"2",...}
```

### 降级机制

脚本内置双层降级：
1. **主方法**: SeleniumBase UC 浏览器 → SSR 数据解析
2. **备用方法**: HTTP 请求 + browser_cookie3 获取本地 Cookie

## 在工作流中的位置

```
评论获取（两层策略）
├── Layer 1: FastMoss product_review_list（主力，不限评论数都先尝试）
│   └── ≥500 评论商品通常返回 10+ 条完整评论
├── Layer 2: 爬虫 SSR 兜底（API 返回 0 时）
│   ├── Batch 5.5 场景: tiktok_product_scraper.py（全量版，同时提取描述/图片/评分分布）
│   └── 仅需评论场景: tiktok_review_scraper.py（本工具，轻量版）
└── 降级: product_detail_info 统计数据（爬虫也失败时，仅评分/评论数）
```

## 注意事项

- 每次运行约 15 秒，不要在循环中大量调用
- 仅获取 SSR 中的 3 条评论样本，**无法翻页获取更多**（TikTok 反爬保护限制，详见上方技术限制表）
- 评分分布是**全量数据**（所有评论的 1-5 星计数），不受 3 条样本限制
- 输出文件会覆盖同 product_id 的旧文件
- 需要系统已安装 Chrome/Chromium 浏览器
