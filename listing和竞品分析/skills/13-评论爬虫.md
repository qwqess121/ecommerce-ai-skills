# 13 - TikTok 评论爬虫工具（v6.2）

> **定位**: 独立工具 Skill，在 FastMoss `product_review_list` 返回 0 条时作为 **Level 1.5** 降级方案获取评论数据。
> 与报告结构无强耦合，适用于任何需要评论原文的场景。
>
> **注意**: 如需同时获取描述正文+图片+评论+评分分布（Batch 5.5 场景），推荐使用**全量版** `tiktok_product_scraper.py`，它复用了同样的 SeleniumBase UC 反爬能力，一次运行提取所有数据。本脚本仅在只需评论时使用。

## 适用场景

- FastMoss `product_review_list` 返回 0 条（评论数 <500 的商品）
- 商品确实有评论（`product_detail_info` 显示评论数 >0）
- 需要评论原文做文本分析或评分分布做量化对比

## 工具信息

| 项目 | 说明 |
|------|------|
| 脚本路径 | `scripts/tiktok_review_scraper.py` |
| 版本 | v5 (Production) |
| 依赖 | Python 3 + SeleniumBase (`pip install seleniumbase`) |
| 耗时 | 约 15 秒/商品 |
| 输出路径 | `scripts/reviews/reviews_{product_id}.json` |

## 使用方法

### 命令

```bash
python scripts/tiktok_review_scraper.py {product_id}
```

**参数**: `product_id` — TikTok Shop 商品 ID（17-19位数字）

**示例**:
```bash
python scripts/tiktok_review_scraper.py 1731494027379118446
```

### 输出字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `product_id` | string | 商品 ID |
| `reviews` | array | 3 条评论原文（source: "ssr"），每条含 review_id/rating/text/user_name/date/country/sku/images |
| `total_reviews` | int | 实际获取的评论条数（通常为 3） |
| `total_reviews_reported` | int | 商品页报告的总评论数 |
| `avg_rating` | float | 3 条样本的平均评分 |
| `avg_rating_page` | float | 全量平均评分（基于所有评论，如 4.3） |
| `rating_distribution_page` | object | 全量评分分布（如 `{"5": 21, "4": 0, "3": 1, "2": 2, "1": 3}`） |

## 技术原理

### 反爬策略

1. **SeleniumBase UC (Undetected Chrome) 模式**：自动绕过 TikTok 反爬检测和 CAPTCHA
2. **SSR 数据提取**：从页面 `<script id="__MODERN_ROUTER_DATA__">` 提取服务端渲染数据
3. **无需登录**：不需要 TikTok 账号，不需要 Cookie

### 数据提取路径

```
SSR JSON 结构:
└── loaderData
    └── product-detail_$id/page
        └── review_info
            ├── review_data → 3 条评论原文
            └── review_ratings
                ├── overall_score → 全量平均评分
                ├── review_count → 总评论数
                └── rating_result → 全量评分分布 {"1":"3","2":"2",...}
```

### 降级机制

脚本内置双层降级：
1. **主方法**: SeleniumBase UC 浏览器 → SSR 数据解析
2. **备用方法**: HTTP 请求 + browser_cookie3 获取本地 Cookie

## 数据级别说明

| 级别 | 数据来源 | 能力 |
|------|---------|------|
| Level 1 | FastMoss `product_review_list` | 全量评论文本（>500 评论商品） |
| **Level 1.5** | **本爬虫工具** | **3 条评论原文 + 全量评分分布** |
| Level 2 | `product_detail_info` 统计数据 | 仅评分/评论数/好评率，无文本 |

### Level 1.5 分析能力

- **可做**: 有限文本分析（3条样本的关键卖点/痛点提取）、完整评分维度量化对比、评分分布可视化
- **不可做**: 全量关键词词频统计、时间趋势分析、大规模情感分析
- **报告标注**: 使用 `△ SSR评论(3条)` 标注数据级别，而非 `✓ API全量`

## 在工作流中的位置

本工具在数据采集阶段（阶段 B）作为 Level 1.5 降级方案使用：

```
阶段 B 本品全量取数
├── B6 评论采集
│   ├── Level 1: product_review_list（优先）
│   ├── ★ Level 1.5: tiktok_review_scraper.py（API返回0时）
│   └── Level 2: product_detail_info 统计数据（爬虫也失败时）
```

对竞品同样执行：如果竞品的 FastMoss 评论也返回 0 条，同样运行此脚本。

## 注意事项

- 每次运行约 15 秒，不要在循环中大量调用
- 仅获取 SSR 中的前 3 条评论，无法翻页获取更多（TikTok Service Worker 限制）
- 输出文件会覆盖同 product_id 的旧文件
- 需要系统已安装 Chrome/Chromium 浏览器
- **不要使用 Chrome MCP 抓取评论**（速度太慢，影响报告生成效率）
