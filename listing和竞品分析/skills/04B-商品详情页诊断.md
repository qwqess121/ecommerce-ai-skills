> **对应**: SKILL.md §七 C → **Section 2.2 图片与详情页**
> 本文件是 SKILL.md 的简要补充，冲突时以 SKILL.md 为准。

## 定位

Section 2.2 专注**视觉层面**：主图/副图/视频/SKU缩略图的质量诊断与优化建议。
描述/文案类诊断已移至 **Section 2.1 标题·描述·SEO**（v6.2 调整），本节不涉及。

## 诊断方式（v6.3.1 变更 — FastMoss 全量图片）

**全部图片通过 FastMoss 产品页提取（E1b），逐张 WebFetch+Read 视觉判定**。禁止 Browser 截图。

```
对本品执行：
1. Browser 打开 FastMoss 产品页 fastmoss.com/e-commerce/detail/{product_id}
2. JS 提取全部 Thumbnail URL（s.500fd.com CDN，5-10张）
3. WebFetch 逐张下载 → Read 逐张视觉分析
4. 无法从图片确认的项标注 ⚠️ 需人工核实
5. 输出图片优化表（5 列，逐张）
```

## TK Shop 官方图片规则（8 条）

| # | 规则 | 判定方式 | 数据来源 |
|---|------|---------|---------|
| 1 | 主图1张+副图≤8张，建议 5–9 张 | 数数量 | E1b FastMoss 产品页提取全部图片 URL，直接计数 |
| 2 | 主图白底/浅色背景、无水印、无促销文字 | 看主图 | E1b 图片 #1 → WebFetch 下载 → Read 视觉分析 |
| 3 | ≥1 张多角度实拍 | 逐张看图 | E1b 全部图片 → WebFetch+Read 逐张视觉判定 |
| 4 | ≥1 张真实使用场景/生活场景 | 逐张看图 | E1b 全部图片 → WebFetch+Read 逐张视觉判定 |
| 5 | ≥1 张卖点信息图（标注/图标/对比） | 逐张看图 | E1b 全部图片 → WebFetch+Read 逐张视觉判定 |
| 6 | 建议含尺寸参照/对比图 | 逐张看图 | E1b 全部图片 → WebFetch+Read 逐张视觉判定 |
| 7 | 多SKU缩略图需可视觉区分 | 看主图 | E1b 图片 #1 + SKU 数据（Batch 1） |
| 8 | 建议 15–60 秒视频，前3秒出卖点 | 查视频 | product_video_list 已在 Batch 2 取回 |

## 输出格式

**图片优化表**（固定 5 列，逐张不留空）：

| 序号 | 图片类型 | 当前（优化前） | 建议（优化后） | 内容说明 |
|------|---------|--------------|--------------|---------|
| 1 | 主图 | [E1b 图1 → Read 视觉描述] | [改进方案] | [依据] |
| 2 | 副图 | ... | ... | ... |

## 评分

图片与详情页维度满分 **10 分**，仅输出 `X/10` 数字，禁止展示权重/公式/进度条。

## 固定输出格式

04B 与 04 合并输出 Section 2.2。输出格式完全遵循 `04-图片视频诊断.md` 的固定输出格式规范（输出 A: 8项审计表 + 输出 B: 5列图片优化表），此处不重复。

04B 补充的执行细节：
1. E1b 提取全部图片：Browser 打开 FastMoss 产品页 → JS 提取 Thumbnail URL → WebFetch 逐张下载
2. 逐张视觉判定：Read 查看每张图片，判定 8 条规则（#1 直接计数，#2-#7 逐张视觉分析）
3. 竞品对比：对 3-5 个竞品用同样 E1b 方法（FastMoss 页面 → JS → WebFetch → Read）
4. 详情页诊断纳入 图片优化表 的末行区域（如"详情页图1/图2…"）
5. 无法从图片直接确认的项标注 ⚠️ 需人工核实
