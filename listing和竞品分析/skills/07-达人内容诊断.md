## 关键判断规则

### 粉丝量与转化脱钩

实测数据表明粉丝量与带货转化无正相关：
- 105K 粉丝达人 = 仅贡献 0.5% GMV
- 48K 粉丝达人 = 贡献 5.0% GMV

逐人列占比才能看出这个现象，不要只看粉丝层级分布做结论。

## 固定输出格式（换任何产品都必须按此结构输出）

Section 1.2 按以下顺序输出，不可调整：

### 输出 1：同形态同口径对比表（表一，固定 8 列）

| 产品 | 达人总数(累计) | 28天活跃达人 | 达人渠道GMV占比 | 商品卡GMV占比 | 广告流量GMV占比 | 28天GMV | 流量结构判断 |
|------|--------------|------------|----------------|-------------|---------------|--------|------------|

- 行：本品（高亮行）+ 同形态 3 席（绿色背景）+ 头部 1-2 款标杆
- 流量结构判断规则：商品卡>80% → "达人引擎未启动" / 视频+直播≥40% → "健康" / 广告>60% → "重广告依赖"
- 表后接 **诊断 callout**（红色 danger），点明本品 vs 对手的最大渠道差距

### 输出 2：本品达人明细表（表二，固定 7 列）

| 达人 | 粉丝 | 视频数 | 带货GMV | 销量 | ★占产品总GMV% | 效果 |
|------|------|--------|--------|------|-------------|------|

- 逐人列出所有达人（5个=5行，不省略）
- 占比 = 该达人累计 product_gmv ÷ 产品累计 total_gmv
- 末行为 **合计行**（加粗，灰色背景）
- 效果列写明具体表现（如"唯一有效，带广告标记"/"零转化"等）
- 表后接 **洞察 callout**（橙色 warn），写明"拆到单人才看得清的两件事"

### 输出 3：佣金策略建议（优化前/优化后对比块）

```
优化前：佣金率 X%，创作者单笔收入 $X.XX，低于均值 X%
优化后：佣金率提升至 X%，创作者单笔收入 $X.XX → $X.XX
依据：[矩阵中佣金率与达人数关联数据]
```

### 输出 4：达人招募策略建议（pin-box 格式）

固定格式：
```
📌 达人与内容行动建议
- [极高] [行动1 + 依据]
- [极高] [行动2 + 依据]
- [高] [行动3 + 依据]
- [高] [行动4 + 依据]
- [中] [30天量化目标：达人数 X→Y+，视频数 X→Y+，占比 X%→Y%+]
```

每条建议必须有数据依据（引用矩阵或达人表中的具体数字）。

### 输出规范

- 全程使用 Markdown 格式输出，禁止输出 HTML 标签和 CSS 类名
