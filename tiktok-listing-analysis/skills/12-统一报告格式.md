# 12 - 统一报告格式规范（v6.2）

> **定位**: 报告 CSS / HTML 骨架。生成报告时**严格按本文件的 CSS 和 HTML 骨架**，确保每次输出视觉一致。
> 冲突时以 SKILL.md 为准。
>
> 视觉体系: **Inter + JetBrains Mono** 字体、**紫色强调色 #6c5ce7**、卡片式布局、亮/暗双主题、**加粗字体权重**。
>
> **★ 格式权威参照**: HoogaLife 2-Pack 报告 Artifact（ef4c6de9）。如有差异以模板为准。
>
> **v6.2 变更**:
> - 报告结构精简为 4 板块：★概览 → Section 1 矩阵(7+3) → Section 2 Listing诊断 → Section 3 风险
> - 六维度评分（满分60），评分只出数字 `X/10`、`X/60`，**禁止进度条**
> - 矩阵转置：维度做行 × 竞品做列，≥16 行 × 12 列（#1–#7 + 同形态3席 + 均值 + 本品）
> - 产品链接用 `<a href>` 可点击跳转，不用 copy-to-clipboard
> - 所有通用标签（本品/竞品A/B）替换为**具体产品名称**

## 一、字体引用

报告 `<title>` 之后、`<style>` 之前放置字体引用：

```html
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800;900&family=JetBrains+Mono:wght@400;500&display=swap">
```

- **Inter** — 正文与标题（权重 400-900）
- **JetBrains Mono** — 数值、代码（权重 400-500）

## 五、评分环（Score Ring）计算

圆环的 `stroke-dashoffset` 根据百分制得分计算：

```
周长 = 2 × π × r = 2 × 3.14159 × 50 = 314.16
```

### Listing 诊断得分环（满分 60）
```
百分比 = diag_score / 60
dashoffset = 314.16 × (1 - 百分比)
```

### 竞争力评分环（满分 10）
```
百分比 = comp_score / 10
dashoffset = 314.16 × (1 - 百分比)
```

### 颜色映射

| 百分比 | 颜色 | CSS 变量 |
|--------|------|---------|
| < 40% | 红色 | `var(--red)` |
| 40%-69% | 橙色 | `var(--orange)` |
| 70%-84% | 黄色 | `var(--yellow)` |
| ≥ 85% | 绿色 | `var(--green)` |

## 九、输出规则清单
