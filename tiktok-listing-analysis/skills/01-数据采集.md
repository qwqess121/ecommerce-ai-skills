# 01 - 数据采集（v6.2）

> **对应 SKILL.md 阶段 A（定位）+ 阶段 B（本品取数）**
> 本文件是操作步骤的展开说明，字段与规则以 SKILL.md 为准。

## 触发条件

用户提供 TikTok Shop 产品链接 / 产品 ID / 关键词 / 店铺名时执行。

## 数据源

- **主**：FastMoss MCP（模式 A）
- **备**：Chrome MCP / Browser pane（模式 B，仅当 FastMoss 不可用）

---

## 阶段 A：定位

### A1. 产品定位

| 场景 | 操作 |
|------|------|
| 给了产品 ID | 直接进入 A2 |
| 给了链接 | 从 URL 提取 product_id |
| 给了关键词 | `product_search` → 展示 TOP 5 让用户确认 |
| 给了店铺名 | `shop_search` → `shop_product_analysis`(seller_id, orderby day28_gmv desc) → 列出 TOP 产品让用户选 |

### A2. 类目定位

```
search_category_by_words({ query: "产品类目关键词" })
```
- 记录 **L3 category_id**（用于后续 `product_rank_top_selling`）
- 记录类目路径（如 Automotive > Interior Accessories > Air Fresheners）

> ⚠ 参数名是 `query`，不是 ~~keywords~~

---

## 阶段 B：本品取数

所有 API 可并行调用（除 shop_base_info 需等 seller_id）。

### B1. 产品基础 — `product_detail_info`

```
product_detail_info({ filter: { product_id } })
```

提取字段：
- `title`（完整，禁止截断）
- `floor_price` + `ceiling_price`（现价区间）
- `commission_rate_percent`
- `product_rating` / `review_count`
- `shipping_fee` / `stock_count`
- `category_sales_rank`（L3 排名）
- `launch_time`（上架时间）
- `total_gmv` / `total_units_sold`（累计）
- `has_paid_promotion`
- `linked_creator_count` / `linked_video_count` / `linked_live_count`
- `cover_url`（主图，用于后续 AI 形态判定）
- `shop.shop_id`（即 seller_id）/ `shop.shop_name` / `shop.shop_total_gmv` / `shop.shop_total_units_sold`

### B2. 流量与渠道 — `product_overview`

```
product_overview({ product_id, time_range_days: 28 })
```

提取字段：
- `period_gmv` / `period_units_sold`（28天）
- `video_gmv_percent` / `live_gmv_percent` / `product_card_gmv_percent`（渠道占比）
- `organic_gmv_percent` / `paid_gmv_percent`（自然 vs 广告）
- `avg_video_play_count`（视频均播）

### B3. SKU 变体 — `product_sku`

```
product_sku({ product_id })
```

**所有 SKU 必须逐行列出**（5个=5行，10个=10行），每行：
- 变体名、价格、28天销量、销量占比、28天销售额、库存
- 商品链接：`https://shop.tiktok.com/us/pdp/-/{product_id}`

### B4. 带货视频 — `product_video_list`

```
product_video_list({ product_id, time_range_days: 28, orderby: "play_count", order: "desc" })
```

> ⚠ **必须传 `time_range_days: 28`**，否则返回空数据

### B5. 达人分析 — `product_creator_analysis`

```
product_creator_analysis({ product_id })
```

提取：达人列表、粉丝量、带货金额、视频数

### B6. 评论数据 — `product_review_list`

```
product_review_list({ product_id })
```

> ⚠ **不传 `time_range` 参数**，传 28d 会返回 0 条
> ⚠ 评论数 < 500 的商品大概率返回 0 条（FastMoss 索引阈值）

**降级方案**：返回 0 条但商品确有评论时 → 运行 TikTok 评论爬虫：
```bash
python scripts/tiktok_review_scraper.py {product_id}
```
输出：`scripts/reviews/reviews_{product_id}.json`（3条原文 + 全量评分分布）

### B7. 店铺数据 — `shop_base_info`

```
shop_base_info({ seller_id })    ← 从 B1 的 shop.shop_id 获取
```

> ⚠ 参数是 `seller_id`，不是 ~~shop_id~~

提取：总销量/总销售额/在售商品数/分类排名/综合评分/好评率/24h回复率/48h发货率/关联达人数/视频数/直播数

**店铺预警规则**：
- 48h 发货率 < 80% → 红色严重警告
- 好评率 < 85% → 黄色警告
- 24h 回复率 < 90% → 黄色警告
- 综合评分 < 4.5 → 黄色警告

## TOKEN 优化

每个 API 调用完成后，**立即提取必要字段，丢弃原始 JSON**。

```
product_detail_info 提取结果:
- title: Car Air Freshener Cup Holder Diffuser 50ML...（完整）
- price: $11.77
- rating: 4.1 (124 reviews)
- commission: 10%
- seller_id: 7438xxxxx
- images: 6张
```

**禁止**：将 FastMoss 返回的完整 JSON（2000-5000字符/次）写入上下文。每个 API 提取 ≤ 15 行。

## FastMoss API 参数速查

| 工具 | 参数 | 正确值 | 常见错误 |
|------|------|--------|---------|
| `search_category_by_words` | 参数名 | `query` | ~~`keywords`~~ |
| `shop_base_info` | 参数名 | `seller_id` | ~~`shop_id`~~ |
| `product_rank_top_selling` | `date_type` | `"week"` | ~~`"weekly"`~~ |
| `product_rank_top_selling` | `date_value` | 已完成的周 `"YYYY-ww"` | 传当前周 |
| `product_review_list` | `time_range` | **不传** | 传 28d 返回 0 条 |
| `product_video_list` | `time_range_days` | **必须传 28** | 不传返回空 |

## 产出与固定输出格式

本步骤产出概览中以下段落的数据。全部用 **Markdown 格式**输出，不输出 HTML。

### ① 诊断产品（9 项信息卡）

固定输出 9 张信息卡，顺序与字段如下：

| # | 信息卡标签 | 内容 | 数据来源 |
|---|-----------|------|---------|
| 1 | 产品链接 | 可点击短 ID | product_id |
| 2 | 产品名称 | 完整标题（禁截断） | detail_info.title |
| 3 | 店铺 | 店铺名 | detail_info.shop.shop_name |
| 4 | 当前售价 | $X.XX（附变体现价/原价；28天成交均价） | detail_info.floor_price + overview |
| 5 | 类目 | L3 类目名 | search_category_by_words |
| 6 | MSKU 变体数 | X 个 [变体类型] | detail_info.sku_count |
| 7 | 评分 / 评论数 | X.X / X 条 | detail_info.product_rating / review_count |
| 8 | 佣金率 / 运费 | X% / $X.XX | detail_info.commission_rate_percent / shipping_fee |
| 9 | 关联达人 / 视频 / 直播 | X / X / X | detail_info.linked_creator/video/live_count |

### ③ 店铺级数据（8 项信息卡 + 预警 callout）

| # | 信息卡标签 | 内容 | 数据来源 |
|---|-----------|------|---------|
| 1 | 店铺名 | — | shop_base_info |
| 2 | 创建日期 | YYYY-MM-DD | shop_base_info |
| 3 | 店铺总GMV | $X | shop_base_info |
| 4 | 店铺总销量 | X 件 | shop_base_info |
| 5 | 在售商品 | X 款 | shop_base_info |
| 6 | 店铺评分 | X.X / 5.0 | shop_base_info |
| 7 | 48h发货率 | X%（<80% 红色） | shop_base_info |
| 8 | 好评率 | X%（<85% 黄色） | shop_base_info |

预警触发规则：48h<80%→红色严重 / 好评率<85%→黄色 / 24h回复<90%→黄色 / 综合<4.5→黄色

### ④ 28天销量趋势

输出 28 根柱状趋势条（每天一根），标注起止日期。零销量天用灰色。

### ⑤ MSKU 变体全行表（固定 10 列）

| # | 变体名 | 现价/原价 | 28天销量 | 销量占比 | 28天GMV | GMV占比 | 库存 | 库存占比 | 状态 |
|---|--------|----------|---------|---------|--------|--------|------|---------|------|

- **逐行列出所有变体**（5个=5行，10个=10行），不合并不省略
- 末行为 **合计行**（加粗，灰色背景）
- 状态列判定规则：库存<10件且日均>1 →「缺货风险」红；库存占比>50%且销量占比<10% →「滞销积压」橙；其余「正常」
- 表后接 **库存销量错配诊断 callout**（红色 danger），写明最严重的 1-2 个错配问题
