# 快速开始 — 员工使用指南

## 前置条件

### 必须
1. **Claude Code** 已安装（桌面版或 CLI 均可）
2. **FastMoss MCP** 已连接且额度充足
   - 一次完整分析约消耗 35-40 次 API 调用
   - 如额度不足会提示充值

### 可选
- **Chrome MCP**：仅在 FastMoss 完全不可用时的备选基础数据源（不用于评论抓取）

## 使用步骤

### 1. 打开项目
在 Claude Code 中打开 `tiktok-listing-analysis` 文件夹：
- 桌面版：文件 → 打开文件夹 → 选择 `tiktok-listing-analysis`
- CLI：`cd` 到该目录后运行 `claude`

### 2. 输入分析请求
直接输入以下任一格式：

```
帮我分析这个产品 [产品链接]
```

```
帮我诊断 [店铺名] 的产品
```

```
分析 [关键词] 类目的竞品
```

**示例**：
```
帮我分析这个产品 https://shop.tiktok.com/view/product/1729440713481294190
```

> **提示**: 如果信息不够（比如没给链接、给了其他平台的链接、只说了店铺名但没指定产品），Claude 会反问你补充信息，按提示回答即可。

### 3. 等待执行
Claude 会自动：
1. 读取 SKILL.md 工作流
2. 调用 FastMoss API 采集数据（~35 次调用）
3. 按 8 步流程逐步分析
4. 生成统一格式的 HTML 报告
5. 发布为 Artifact（可分享链接）

整个过程约需 5-10 分钟，中途无需干预。

### 4. 获取报告
分析完成后会得到：
- 一份完整的 HTML 报告（Artifact 链接）
- 报告包含 9 大板块、双评分体系

## 报告包含什么

| 板块 | 内容 |
|------|------|
| 诊断总览 | 产品数据 + 店铺数据 + 市场大盘 + SKU分析 + 趋势图 |
| TOP 10 竞品矩阵 | 增强版含评论/视频/达人三维度 |
| 竞品深度分析 | 8 个子章节，商品维度全面拆解 + VOC消费者洞察对比 |
| 七维诊断详情 | 标题/图片/SEO/定价/达人/合规/商品详情页逐项诊断 |
| 达人贡献矩阵 | TOP 达人排名与带货数据 |
| 创作者生态对比 | 6 级达人分布 + 合作模式判定 |
| 优化建议 | 标题优化前后对比 + 佣金策略 + 内容策略 |
| 行动清单 | 7天/30天/90天分阶段执行 |
| 风险评估 | 高/中/低风险及应对措施 |

## 常见问题

### Q: FastMoss 提示余额不足怎么办？
A: 登录 FastMoss 后台充值。一次完整分析约需 35-40 个额度。

### Q: 报告中某些数据显示 "≈" 是什么意思？
A: 表示该数据为估算值（API 未直接返回），根据其他已知数据推算得出。

### Q: 能只跑竞品分析不跑 Listing 诊断吗？
A: 目前是合并工作流，建议完整跑一遍。如果只需要部分内容，可以告诉 Claude "只帮我做竞品分析部分"。

### Q: 报告样式和之前不一样怎么办？
A: 确保 Claude 读取了 `skills/12-统一报告格式.md`。如果样式仍不对，可以提示 Claude "请严格按照 12-统一报告格式.md 的 CSS 系统生成报告"。

### Q: 评论数据返回 0 条怎么办？
A: FastMoss 评论 API 仅对评论量 >500 的商品返回文本数据。新品或评论少的产品会返回 0 条，这是 FastMoss 的数据覆盖策略。工作流会自动跳过评论文本分析，使用 detail_info 中的评分/评论数/好评率做量化对比。当评论积累到 500+ 后可重新运行获取完整 VOC 洞察。

### Q: 可以分析非 US 市场吗？
A: 工作流默认分析 US 市场。如需其他市场，在请求中注明，如 "帮我分析 UK 市场的这个产品"。
