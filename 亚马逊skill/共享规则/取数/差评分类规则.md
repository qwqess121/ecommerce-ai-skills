# 差评分类规则（统一口径）

适用于所有模块中出现的差评类别数字。分类结果的唯一来源是数据目录中的 `reviews/classification_<ASIN>.json`，计数由 `工具/差评分类.py stat` 计算。报告中的差评数字必须与该文件的 `summary` 一致。

## 1. 样本

- 数据：`reviews/<ASIN>_neg.json` 的 `data.items`，即第 1 页 20 条（星级 1–3）。`data.total` 为全量条数，只用于说明，不参与计数。
- 好评（`reviews/<ASIN>_pos.json`）不参与分类。
- 报告中写明样本条数与全量条数，不做全量外推。

## 2. 四个类别

| 类别 | 判定（阅读 content 原文） | 不属于 |
|---|---|---|
| 留香不足 | 闻不到味；香味很快消失或持续时间短；需要反复翻转或摇晃才有味；香味弱；直接说不好用、不工作 | 只写瓶盖问题的 |
| 渗漏 | 漏油、溢出、滴漏；油流到车内、衣物、仪表台或后视镜 | 只写香味的 |
| QC | 瓶盖或塞子松、弹开、破损、开裂；绳子断；缺件或数量不对；瓶身破损 | 纯粹渗漏描述、纯粹香味描述 |
| 其他 | 尺寸、颜色、价格、包装外观、与产品无关的抱怨等，不属于以上三类 | 任何一个具体类别 |

## 3. 计数规则

- 每条至少归入一类。
- “其他”只能单独出现；一条同时含“其他”与其他类时，去掉“其他”。
- 一条可同时计入多类（如既渗漏又 QC），计入“重叠”。
- “渗漏或 QC（去重）”= 至少含渗漏或 QC 之一的条数。
- 比例 = 条数 ÷ 样本条数（20），写公式。
- 均值（多个对象）= 各对象条数之和 ÷ 对象数，写公式。

## 4. 操作步骤

1. `差评分类.py template <数据目录> <ASIN>`（每个对象一次）生成骨架。
2. 阅读每条 `excerpt`（或完整 content），按第 2 节填写 `categories`；可用 `import` 批量导入。
3. `差评分类.py stat <数据目录>` 校验并统计，退出码必须为 0。
4. 报告中引用 `summary` 中的数字，并在表下写明规则与样本量。

## 5. 与报告的对应

- 模块 1：3.1 核心差评问题矩阵。
- 模块 2：1.5 差评对比矩阵。
- 模块 3：2.2 差评编码表。
- 模块 5：3.1 与 2.2 中引用差评数字的位置。
- 总览：引用的差评数字必须与上述一致。
