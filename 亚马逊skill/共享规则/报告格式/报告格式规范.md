## 二、排版规范

### 2.1 字体定义

```css
/* 中文、日文、韩文：Noto Sans SC */
body, .content-section {
  font-family: 'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif;
}

/* 英文、数字：Manrope（用于标题、数值、导航标签） */
h1, h2, h3, h4, h5, h6, 
.navlabel, .modcard-num, .kpi-value, .brand-name, 
.summary-label, .finding-label, strong {
  font-family: 'Manrope', 'Noto Sans SC', -apple-system, BlinkMacSystemFont, sans-serif;
}

/* 代码 & 等宽 */
code, pre {
  font-family: ui-monospace, 'SF Mono', Consolas, 'Cascadia Code', monospace;
}
```

### 2.2 字号与字重规范

| 元素 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| **h1** | 26px | 900 | 1.65 | 报告标题（单份报告仅 1 个） |
| **h2** | 19px | 700 | 1.65 | 模块标题、章节标题 |
| **h3** | 16px | 700 | 1.65 | 子章节标题 |
| **h4** | 14px | 700 | 1.65 | 小标题、图表标题 |
| **h5** | 13px | 700 | 1.65 | 极小标题 |
| **正文 p** | 14px | 400 | 1.7 | 段落文本 |
| **表格** | 13px | 400 | - | thead/tbody 统一 13px |
| **列表 li** | 14px | 400 | 1.7 | 列表项 |
| **强调 strong** | 继承 | 700 | - | 加粗关键词 |
| **标签** | 12px | 500 | - | 导航标签、KPI 标签 |
| **小字** | 11–12px | 400 | - | 备注、脚注、时间戳 |
| **数值** | 18px (KPI) | 800 | 1.65 | KPI 数字、模块编号 |

### 2.3 间距规范

| 元素 | 值 | 用途 |
|------|-----|------|
| **段落间距** | 14px (bottom) | 每个 p 的下间距 |
| **标题到内容** | h1 下 12px，h2 下 16px，h3 下 12px | 标题与后续内容的距离 |
| **块级元素间距** | 18–28px | 表格、列表、区块间的垂直距离 |
| **表格行高** | 12px 上下 padding + 11px 左右 padding | td/th 统一 |
| **卡片 padding** | 14–18px | 内部文本到卡片边缘的距离 |
| **侧边栏 padding** | 22px (brand), 20px (navlist) | 竖向页边距 |
| **主内容区 padding** | 40px 水平，48px 竖向 | 页面总页边距 |

### 2.4 字间距与字体样式

| 样式 | 值 | 应用位置 |
|------|-----|----------|
| **Letter-spacing** | 0.06em | 品牌名（.brand-name） |
| **Letter-spacing** | 0.04em | 标签前缀（.summary-label 等） |
| **Letter-spacing** | 0.02em | KPI 标签（.kpi-label） |
| **Text-transform** | uppercase | 导航编号、标签前缀 |
| **Text-wrap** | balance | h1 标题（让宽度均衡） |
| **Font-variant-numeric** | tabular-nums | 数据表格（td/th）、数值（.kpi-value） |

## 三、组件样式详解

### 3.1 导航侧边栏（.sidebar）

#### 容器属性
```css
.sidebar {
  width: 252px;              /* 固定宽度 */
  flex: none;
  background: var(--surface);
  border-right: 1px solid var(--border);
  position: sticky;
  top: 0;
  height: 100vh;             /* 全屏高 */
  overflow-y: auto;
  padding: env(safe-area-inset-top, 0px) 0 20px;
  display: flex;
  flex-direction: column;
}
```

#### 品牌名区域（.brand）
- 顶部 padding：22px 20px 14px
- 下边框：1px solid var(--border)
- .brand-name：13px / 800 / uppercase / letter-spacing 0.06em / 翠绿色
- .brand-sub：12px / 行高 1.6 / text-muted / margin-top 8px

#### 导航项（.navitem）
- 尺寸：10px 12px padding / 宽 100% / border-radius 8px
- 活跃态：background 改为 accent-soft，文字改为 accent-strong
- 悬停态：background 改为 surface-2
- 过渡：all 0.15s ease

#### 导航编号（.navnum）
- 13px / font-weight 700 / Manrope / 宽 20px flex:none
- 活跃态：color accent，font-weight 800

### 3.2 KPI 网格（.kpi-grid）

写法（写在 Markdown 中，原样保留 HTML）：

```html
<div class="kpi-grid">
  <div class="kpi"><span class="kpi-label">本品定价</span><span class="kpi-value">$16.99</span></div>
  <div class="kpi"><span class="kpi-label">评分 / 评论数</span><span class="kpi-value">4.1★ / 187</span></div>
</div>
```

样式（已写入 `scripts/template.html`，颜色使用模板的 token 名）：

```css
.kpi-grid { display: grid; grid-template-columns: repeat(4, minmax(0, 1fr)); gap: 12px; margin: 22px 0 32px; }
.kpi { background: var(--card); border: 1px solid var(--line); border-radius: 8px; padding: 16px;
       display: flex; flex-direction: column; gap: 8px; min-width: 0; }
.kpi-label { font-size: 12px; color: var(--muted); font-weight: 500; letter-spacing: 0.02em; }
.kpi-value { font-size: 18px; font-weight: 800; color: var(--accent); font-variant-numeric: tabular-nums; }
```

手机宽度（≤820px）时 KPI 网格变为 2 列。KPI 数值用于对比与概览，不替代表格。

### 3.3 模块卡片（.modcard）

写法（用锚点链接到模块，和侧边导航一样由 `hashchange` 切换）：

```html
<div class="mod-grid">
  <a class="modcard" href="#m1">
    <span class="modcard-num">01</span>
    <h3>产品开发</h3>
    <p>这个模块回答的问题</p>
    <span class="modcard-tag">模块包含的内容概要</span>
  </a>
</div>
```

样式：

```css
.mod-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(230px, 1fr)); gap: 14px; margin: 22px 0 34px; }
.modcard { background: var(--card); border: 1px solid var(--line); border-radius: 8px; padding: 18px;
           display: flex; flex-direction: column; gap: 8px; color: var(--fg); text-decoration: none; }
.modcard:hover { border-color: var(--accent); transform: translateY(-2px); box-shadow: 0 4px 12px rgba(0,0,0,.08); }
.modcard-num { font-size: 13px; font-weight: 800; color: var(--accent); text-transform: uppercase; letter-spacing: 0.04em; }
.modcard h3 { margin: 0; font-size: 16px; font-weight: 700; color: var(--fg); }
.modcard p { font-size: 13px; color: var(--muted); margin: 0 0 8px; flex: 1; line-height: 1.6; }
.modcard-tag { font-size: 12px; color: var(--muted); border-top: 1px solid var(--line); padding-top: 10px; }
```

手机宽度时模块卡片为单列。卡片的 `href` 必须与模块的 section id 一致（`#m1` … `#m5`）。

**没有总览页时（不写 overview.html）**：`build.js` 自动在第一个模块页的 H1 之后生成模块卡片行，链接 `#m1` … `#m5`（只列实际存在的模块）。卡片标题取模块名，正文取该模块的第一个 H2，标签为该模块的 H2 数量。只有一个模块时不生成。

### 4.4 导航与内容同步机制

1. 侧边栏一个 `.navitem`（data-target 指向对应 section id）

- 总览：data-target="overview"，id="section-overview"
- 模块 1：data-target="m1"，id="section-m1"
- 模块 2：data-target="m2"，id="section-m2"
- ...以此类推

## 五、特殊元素规范

### 5.1 页面标题（h1）

- 仅出现一次（在报告总览或模块顶部）
- 26px / 900 / 下 margin 12px
- `text-wrap: balance` 让宽度均衡
- `letter-spacing: -0.01em` 微调紧凑感

### 5.2 模块标题（h2）

- 19px / 700
- 上 margin 32px，下 margin 16px
- 上边框：1px solid var(--border)
- 上 padding 6px，下 padding 6px
- `scroll-margin-top: 24px`（点击导航时的滚动偏移）

### 5.3 数值格式化

- 月销量、价格、排名等数值统一使用 `font-variant-numeric: tabular-nums`（等宽数字）
- KPI 数值：18px / 800 / accent-strong 色
- 百分比：同上（如 "+15.1%"、"−5.52%"）
- 货币：前缀 $，后跟数值（如 "$9.99"）

### 5.4 优先级标记

- **P0/P1/P2**：用粗体文字标记（如 `<strong>P0 关键</strong>`），配合所在块的颜色
- **✅ / ❌ / ⚠️**：用 emoji 标记判定结果（无需额外样式）
- **实施中 / 待验证**：用行内标签或粗体标记

### 5.5 图标与符号

- 上升：⬆️ / ↗️
- 下降：⬇️ / ↘️
- 警告：⚠️
- 对勾：✅
- 叉号：❌
- 圆点列表：用原生 `<ul>` 和 `<li>`
- 序号列表：用原生 `<ol>` 和 `<li>`

### 5.6 代码块

```css
pre {
  background: var(--code-bg);
  color: var(--code-text);

  border-radius: 6px;
  overflow-x: auto;
```

## 七、禁止项（格式 100% 保持一致的保证）

### 禁止修改

❌ **绝不能自行添加新颜色**
- 所有颜色必须从已定义的 CSS 变量中选用
- 不能自创新的块颜色（如绿色块、黄色块）

❌ **绝不能改变表格结构**
- 不能删除或添加表格列
- thead/tbody 标签顺序固定
- th/td 的对齐方式（text-align: left）固定

❌ **绝不能改变标题层级**
- h1 = 报告标题（仅 1 个）
- h2 = 章节标题
- h3 及以下 = 小标题
- 不能跳级（如直接 h1 → h3）

❌ **绝不能修改组件样式**
- 卡片的 border-radius（8px）
- 内容块的 padding（14px 18px）
- 导航按钮的尺寸（10px 12px）
- KPI 数值的字号（18px）

❌ **绝不能调整版面布局**
- 侧边栏宽度固定 252px
- 主内容区 max-width 固定 880px
- padding 数值不能改（40px 48px 80px）

❌ **绝不能省略任何内容块类型**
- 数据表格必须用 `tablewrap` 容器包裹
- 如果有修正声明，必须用 `.caveat-box`（不能改成其他颜色）
- 小结、发现的出现顺序（小结 → 发现）相对固定
