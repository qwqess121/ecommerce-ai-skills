# 竞品匹配标准与评分规则（全局共用）

> 所有模块的 skill 在做"竞品对比"时，必须先用本文件的匹配标准筛出"真正可比的竞品"，再用统一的评分公式打分，不能拿泛泛的同类目产品或模糊的"高/中/低"打发。
>
> 设计参考：funewa/AMZ-VOC（73-skill 评论情报仓库）的 `industry-benchmark`（百分位对标，不是简单和1-2个竞品比）、`competitor-features`（按字段做特性矩阵而非文字描述）、`product-improve`（"受影响人数×严重度"的量化优先级公式）三个设计思路。

## 一、竞品匹配标准（三个条件必须同时满足，缺一个就不算可比竞品）

| 条件 | 判定方法 | 数据来源 |
|---|---|---|
| **属性一致** | 同一个类目叶子节点（`nodeIdPath`完全一致，不能只是同大类）；重量/尺寸在±30%区间内 | 卖家精灵 `asin_detail`（`nodeIdPath`/`weight`/`dimensions`） |
| **外观/形态一致** | 产品形态关键词必须完全匹配（例："vent clip"不能拿"hanging diffuser"来比，"杯架插棒"不能拿"喷雾瓶"来比），从标题/features里提取形态词做匹配 | 卖家精灵 `asin_detail`（`title`/`features`） |
| **使用场景一致** | 目标场景相同（例：都是车内使用，不能拿家用香薰凑数）；目标人群/使用频率描述相近 | 卖家精灵 `asin_detail`（`overviews`/`features`）+ 人工判断场景描述 |

**执行规则**：先用 `product_research` 或 `asin_competitor` 拉一批候选竞品，再逐个用上表三条过滤，被过滤掉的候选竞品要在报告里注明"排除原因"（比如"形态不符：喷雾瓶 vs 我方杯架插棒"），不能悄悄跳过筛选直接开始对比。**竞品数量最低要求：过滤后至少保留3个可比竞品才能出对比结论，少于3个要明确标注"样本不足，结论仅供参考"。**

## 二、评分规则

### 1. 机会/需求评分（用于选品判断，1-10分）

```
机会评分 = 需求分(0-4) + 竞争分(0-3) + 利润分(0-3)

需求分：
  月搜索量 ≥ 5万 → 4分
  1万-5万 → 3分
  3千-1万 → 2分
  <3千 → 1分

竞争分（供需比 = 搜索量/在售商品数，供需比越高竞争越弱）：
  供需比 ≥ 10 → 3分
  5-10 → 2分
  <5 → 1分

利润分（基于真实供应商报价或领星真实COGS算出的预估净利润率）：
  ≥25% → 3分
  15-25% → 2分
  <15% → 1分（COGS未知时此项计0分，并在报告里标注"利润分未计入，样本不完整"）
```

### 2. 行业对标百分位（用于判断自己在竞品里处于什么位置，不是简单"高于/低于平均"）

对每个核心指标（评分、价格、BSR、月销量、退货率），在筛出的可比竞品集合里排序，报告"你排在第几名/共N个"和"处于Top X%"，而不是只说"高于/低于均值"。

```
百分位 = (比你差的可比竞品数量 / 可比竞品总数) × 100%
```

例："评分3.9分，在5个可比竞品里排第4，处于后20%" 比"评分低于均值4.2"信息量大得多——后者不知道差距大小和排名，前者直接知道位置。

### 3. 行动优先级评分（用于差评/问题类的优先级排序，替代模糊的P1/P2/P3标签）

```
优先级分 = 受影响比例(1-5) × 严重度(1-5)

受影响比例：
  该问题在差评里占比 ≥50% → 5分 | 30-50% → 4分 | 15-30% → 3分 | 5-15% → 2分 | <5% → 1分

严重度：
  涉及财产/人身损害或大量退货 → 5分
  导致核心功能失效 → 4分
  明显影响体验但功能仍可用 → 3分
  轻微不便 → 2分
  纯主观偏好差异 → 1分

分级：
  ≥15分 → P1（本周处理）
  8-14分 → P2（本月处理）
  <8分 → P3（观察，暂不处理）
```

### 4. 财务健康度评分（存量产品，替代"高于/低于类目估算"）

**硬性前提**：必须用领星ERP真实数据，卖家精灵的类目profit字段只能做背景参考，不能计分。

```
财务健康分 = 毛利率分(0-5) + 趋势分(0-5)

毛利率分：
  ≥25% → 5 | 15-25% → 4 | 8-15% → 3 | 3-8% → 2 | <3% → 1

趋势分（月环比变化）：
  上升 → 5 | 持平(±2pp内) → 3 | 下滑<30% → 2 | 下滑≥30% → 0（触发P1紧急排查，不管当前毛利率多少）
```

## 三、统一决策规则（产品开发不分新老，同一套阈值）

不管是"要不要开发一个新产品"还是"已上架产品要不要继续投入"，用同一张决策表：

| 机会评分（选品维度，新品适用；存量产品用财务健康分代替） | 行业对标位置 | 决策 |
|---|---|---|
| ≥8分 且 对标百分位前50% | 领先或持平 | **继续投入 / Go**：加大库存、广告、可以考虑同形态扩品 |
| 5-7分 或 对标百分位后50% | 落后但有差异化空间 | **优化后再投入 / Hold**：先解决明确的P1问题（用行动优先级评分排出的最高分项），复查后再决定 |
| <5分 且 财务健康分<5 | 全面落后 | **暂缓 / Pause**：不追加投入，观察1个周期 |
| 财务健康分连续2个月为0（趋势分触发） | — | **立即止损 / Stop**：不管其他分数多高，先处理骤降问题 |

## 四、每个模块必须做的竞品对比动作（不能省略）

| 模块 | 竞品对比动作 | 用哪个MCP |
|---|---|---|
| 1-产品开发 | 匹配竞品的真实利润率区间对比（供应商报价互相印证） vs 财务健康分 | 卖家精灵`asin_detail`/`product_research`；领星ERP真实毛利 |
| 2-竞品销售策略分析 | 匹配竞品的关键词覆盖率、价格位置百分位、评论情感对比 | 卖家精灵`asin_competitor`/`traffic_keyword`/`review`；SIF关键词分布 |
| 3-Listing诊断 | 逐字段对比标题/五点/图片数量/A+模块数，跟匹配竞品做特性矩阵而不是泛泛描述 | 卖家精灵`asin_detail`；Brightdata抓竞品Listing全文 |
| 4-广告策略分析 | 匹配竞品的广告结构规模（Campaign数、SP/SB/SD占比）对比 | SIF`ads_get_asin_ad_structure`（可查任意ASIN，不需要对方账户授权） |
| 5-内容生产工具 | 匹配竞品的评论痛点/好评关键词对比，找内容差异化空档 | 卖家精灵`review`；Brightdata抓竞品图片 |
| 6-站外营销自动化 | 匹配竞品的促销/优惠券历史、Vine使用情况对比 | 卖家精灵`asin_coupon_trend` |
