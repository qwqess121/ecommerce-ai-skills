## 一、HTML 结构检查

- [ ] DOCTYPE 正确：`<!doctype html>`

- [ ] 标题标签存在：`<title>HoogaLife 决策报告</title>` 或相似
- [ ] Google Fonts 导入正确：`Noto+Sans+SC` 和 `Manrope`

### 1.2 CSS 变量完整性

在 `<style>` 中检查所有变量是否已定义：

**基础配色**
- [ ] `--bg`（页面背景）
- [ ] `--surface`（卡片/表格背景）
- [ ] `--surface-2`（悬停状态）
- [ ] `--border`（边框色）
- [ ] `--text`（正文色）
- [ ] `--text-muted`（次要文字）
- [ ] `--text-faint`（弱化文字）
- [ ] `--accent`（强调色）
- [ ] `--accent-soft`（强调色软）
- [ ] `--accent-strong`（强调色深）

**内容块颜色**
- [ ] 小结色系：`--summary-bg`, `--summary-border`, `--summary-text`, `--summary-label`
- [ ] 发现色系：`--finding-bg`, `--finding-border`, `--finding-text`, `--finding-label`
- [ ] 表格色系：`--table-bg`, `--table-border`, `--table-text`
- [ ] 信息色系：`--info-bg`, `--info-border`, `--info-text`
- [ ] 警告色系：`--warning-bg`, `--warning-border`, `--warning-text`
- [ ] 代码色系：`--code-bg`, `--code-text`

**亮色/暗色切换**
- [ ] `@media (prefers-color-scheme: dark)` 中所有变量都重新定义
- [ ] `:root[data-theme="dark"]` 中所有变量都重新定义

### 1.3 侧边栏结构

- [ ] 页脚（.sidebar-foot）存在且包含：

### 1.4 主内容区结构

## 常见问题排查

### 报告在手机上显示混乱

**检查清单：**
1. [ ] 在 @media (max-width: 760px) 中是否有样式被意外删除
2. [ ] 侧边栏是否正确切换为水平布局
3. [ ] KPI 网格是否从 4 列变为 2 列
4. [ ] 主内容 padding 是否正确调整

### 某个块的颜色显示错误

**检查清单：**
1. [ ] 该块的 CSS 变量是否拼写正确（--summary-bg vs --summarybg）
2. [ ] 该块的 class 是否正确（.summary-block vs .summary_block）
3. [ ] 亮色/暗色模式中该变量是否都被定义
