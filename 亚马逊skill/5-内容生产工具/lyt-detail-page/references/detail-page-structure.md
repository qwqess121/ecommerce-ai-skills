# 商品详情页信息结构

这个文件用于选择详情页模块和安排信息顺序。模块是候选项，不是固定模板。

## 选择原则

详情页顺序由用户的购买疑问决定：

```text
先看懂产品
→ 确认与自己有关
→ 理解购买收益
→ 相信产品能做到
→ 看清细节与使用方式
→ 排除规格和风险疑虑
```

每一屏只承担一个主要任务。相邻两屏表达相同信息时，合并或删除其中一屏。

## 候选模块

| 模块 | 主要回答 | 最低事实要求 | 常见视觉证据 |
| --- | --- | --- | --- |
| 首屏 | 这是什么，为什么值得继续看 | 产品名称、用途、核心收益 | 清晰产品主体、核心使用结果或场景 |
| 问题场景 | 它与我有什么关系 | 目标用户、真实使用场景 | 用户问题发生的环境或动作 |
| 核心收益 | 我购买后得到什么 | 已确认收益及支持事实 | 使用前后状态、结果展示或场景 |
| 功能机制 | 它为什么能提供该收益 | 功能、结构或工作方式 | 结构拆解、动作路径或局部特写 |
| 关键细节 | 产品有什么不同 | 已确认结构、材质或工艺 | 特写、剖面、尺寸或细节标注 |
| 使用场景 | 在哪里、何时、怎样使用 | 适用场景和限制 | 真实空间、人物动作或环境 |
| 使用步骤 | 我会不会用 | 已确认操作步骤 | 1-2-3 步骤图或连续动作 |
| 规格与 SKU | 我该买哪个 | 尺寸、容量、颜色、数量、型号 | 规格表、尺寸图和选项对照 |
| 包装清单 | 我会收到什么 | 包装内含物 | 平铺清单或包装展示 |
| 信任信息 | 我凭什么相信 | 真实认证、检测、保修或售后 | 证书、测试过程或服务说明 |
| FAQ | 还有哪些购买风险 | 已确认问题与答案 | 简洁问答、图标或局部辅助图 |

## 模块删减

- 产品简单、决策成本低：优先保留首屏、核心收益、关键细节、规格。
- 使用方式陌生：增加功能机制和使用步骤。
- SKU 多或兼容性复杂：提前展示规格与适配范围。
- 安全、材质或功效敏感：只有证据充分时加入信任信息。
- 用户只做局部模块：保留该模块所需的前置信息，不补成完整长页。

## 文案要求

- 主标题只表达一个主要信息。
- 辅助文案负责解释条件、对象或证据，不重复主标题。
- 功能描述和用户收益分开写，不能把功能直接夸大成结果。
- 规格、单位、型号和兼容范围保持用户原文或可靠资料原文。
- 本地化不是直译；语言、单位和表达应适配目标市场。
- 没有证据的比较级、最高级和绝对化承诺删除。

## 页面衔接

检查每个模块之后，用户自然产生的下一个问题是什么。下一屏应回答这个问题。

常见衔接：

```text
产品是什么 → 为什么需要 → 能获得什么 → 为什么可信
→ 具体怎么用 → 有哪些规格 → 购买前还有什么风险
```

模块不能仅靠「还有更多卖点」连接。无法说明某一屏存在理由时，删除该屏。
