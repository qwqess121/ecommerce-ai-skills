# 详情页图片生产规则

这个文件用于生产版和成品版。目标是保证产品身份、文字和页面尺寸可控。

## 生产顺序

```text
确认模块清单
→ 锁定产品视觉身份
→ 生成全部独立分屏预览
→ 逐张修改并确认
→ 拼接长图
```

不要让图片模型一次生成整张长图。长图会放大产品漂移、文字乱码、模块重复和比例失控。

## 全量分屏预览

方案只能确认信息、模块和视觉方向，不能让用户提前发现所有裁切、位置、比例、遮挡和排版问题。因此，完整生产前必须设置视觉确认点。

默认预览页面方案中的全部模块，不能只抽查首屏、人物图或高风险模块。后续模块同样可能出现裁切、比例、文字和风格问题，必须在拼接前逐张验收。

预览与最终版必须使用相同的：

- 宽高比和图片框。
- 主体素材和裁切方式。
- 网格、安全边距与文字区域。
- 产品占比、圆角和相邻元素关系。

每张预览都必须保存最终输出分辨率的原文件。界面为了浏览可以显示缩略图，但不能只保留低分辨率预览。用户确认一个模块后锁定该模块；修改其他模块、拼接长图或导出文件时，不得重新生成或改变已确认模块。

视觉反馈以「模块编号 + 修改对象 + 目标状态」记录，例如：

```text
02：只调整主图裁切；图片框不动；眼睛主体上移至画面中部；文案和其他元素保持不变。
```

不要要求用户在生成前给出其无法预知的百分比。预览产生后，可以根据实际画面把反馈转换为位置、比例和安全区参数。

## 产品身份锁定

优先保留：

- 产品外轮廓和比例
- 部件数量和连接关系
- 颜色、纹理和可见材质外观
- 包装结构
- logo、标签和可见文字
- 用户明确要求保留的细节

产品身份要求高时，优先使用用户原始产品图进行抠图、合成和调色。图片模型主要生成背景、场景、人物、道具、光线和氛围。

只有用户明确允许重新渲染产品时，才让图片模型重建产品。重建后仍需逐项比对结构和包装。

## 参考图使用

参考图可以控制：

- 页面节奏
- 构图和镜头
- 场景类型
- 色彩关系
- 光线和质感
- 信息密度

参考图不能提供：

- 用户产品的功能与规格
- 品牌、包装和 logo
- 认证、评价、销量和排名
- 未经确认的促销与售后

提示词中明确区分：

```text
参考图只控制构图与视觉风格。
产品图只控制产品身份、结构、颜色和包装。
```

## 文字生产

- 图片模型生成的文字只能作为占位，不作为最终交付。
- 主标题、slogan、辅助文案、规格、单位、品牌和按钮使用 HTML/CSS、设计工具或其他确定性排版方式添加。
- 最终排版文字必须与已确认文案逐字核对。
- logo 优先使用用户提供的原始文件，不由图片模型重绘。
- 文字与背景对比度不足时，调整背景或增加稳定的承载区域，不依赖模糊阴影补救。

### Slogan 排版

- Slogan、主标题和辅助文案必须形成明确层级，不能使用相同字号和字重。
- Slogan 默认只进入用户确认的首屏、品牌模块或收尾模块。
- 用户提供原文时保持字词、大小写、标点和语言不变。
- 需要换行时优先按语义断句，不拆散品牌名、产品名和固定短语。
- 预览时检查 slogan 是否抢占产品主体、是否与主标题重复、是否在移动端宽度下溢出。

## 分屏规则

每个分屏固定：

- 输出尺寸和宽高比
- 安全边距
- 产品占比
- 标题区域
- 辅助文案区域
- 背景延展方式

同一详情页保持：

- 网格和边距一致
- 字体层级一致
- 产品颜色一致
- 光线方向不过度跳变
- 色彩系统有主色、辅助色和中性色

不要用同一个构图重复替换文案。相邻模块需要有信息变化，也需要有视觉节奏变化。

## 图片提示词结构

```text
产品身份与必须保留细节
→ 模块目标
→ 主体动作与场景
→ 构图与镜头
→ 产品位置和比例
→ 光线与色彩
→ 材质与真实感
→ 文字留白区域
→ 输出比例
→ 禁止生成内容
```

禁止生成内容至少覆盖：

- 改变产品结构、颜色、数量或包装
- 新增 logo、认证、文字或配件
- 产品变形、悬浮、穿模或比例异常
- 无关促销标签和价格
- 参考图品牌与产品身份

## 长图拼接

- 任意一个分屏尚未确认时，不进入最终长图拼接。
- 拼接只读取已经确认的分屏文件，不重新调用图片生成工具。
- 所有分屏宽度一致后再拼接。
- 拼接处不能截断标题、人物、产品或步骤。
- 背景需要连续时，提前设计上下延展区域。
- 不需要连续时，使用明确的版块切换，避免出现误以为加载断层的空白。
- 同时保留分屏源文件，不能只交付一张不可修改的长图。

## 成品检查

至少检查：

1. 产品与原图是否一致。
2. 页面文字是否逐字正确。
3. 是否存在错误规格、单位或 SKU。
4. 是否混入参考图元素。
5. 是否存在图片模型生成的乱码。
6. 是否有产品、人物和文字重叠。
7. 是否有不自然的手部、接触关系和使用动作。
8. 分屏宽度、边距和色彩是否一致。
9. 长图拼接处是否完整。
10. 文件名称能否对应模块顺序。

当前宿主不能完成图片生成、抠图、排版或拼接中的某一步时，明确标注未完成环节，并交付可继续执行的生产文件，不伪装成最终成品。
